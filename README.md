# Conversor de Divisas — Interfaz Gráfica de Cambio de Moneda

Aplicación web interactiva diseñada para realizar conversiones entre distintas divisas de forma rápida y precisa. Cuenta con una interfaz gráfica limpia e intuitiva que permite seleccionar monedas de origen y destino, ingresar montos y visualizar el resultado equivalente al instante.

## Características principales
* **Conversión de monedas en tiempo real:** Cálculo automático e inmediato del valor equivalente según la tasa de cambio seleccionada.
* **Selección dinámica de divisas:** Menús desplegables intuitivos para alternar fácilmente entre diferentes monedas internacionales.
* **Interfaz gráfica clara y responsiva:** Diseño visual enfocado en la usabilidad, adaptable a pantallas de escritorio y dispositivos móviles.

## Lenguajes y herramientas utilizadas
* **Desarrollo Web:** HTML5, CSS3, JavaScript
* **Control de versiones:** Git y GitHub Desktop
